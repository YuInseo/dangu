# 동행

교통약자 승하차 도움 쪽지를 팀이 같이 보는 앱. 종이 쪽지를 들고 다니던 것을 폰으로 옮겼습니다.

종이 쪽지는 한 장이라 그걸 쥔 사람만 볼 수 있었습니다. 동행에서는 한 사람이 적으면 팀 모두의
폰에 바로 뜨고, 누가 맡았는지·끝났는지도 그 자리에서 같이 바뀝니다.

- **쪽지 칸은 종이 양식 그대로** — 출발/도착, 시간, 열차번호, 홈, 구간(○○행 / ○○에서 온),
  좌석번호(호차-좌석), 내용(휠필·리프트·시각·무표), 그리고 손으로 적던 만날 곳·연락처·메모.
- **쪽지판** — 하루치 쪽지가 열차 시각 순서로. 남은 시간("12분 후")이 보이고, 10분 안쪽이면
  빨갛게 바뀝니다. 끝난 쪽지는 아래로 내려가고, 숨길 수도 있습니다.
- **맡기 → 완료** — "내가 맡기"를 누르면 팀 모두의 화면에 내 이름이 붙습니다. 두 사람이 같은
  고객을 모시러 가는 일이 없습니다.
- **새 쪽지 알림** — 다른 사람이 쪽지를 올리면 진동과 함께 위에 알림이 뜨고, 그 쪽지에 노란
  테두리가 생깁니다.
- **공유** — 앱이 없는 사람(다른 역, 차장)에게는 쪽지를 글로 만들어 카톡 등으로 보냅니다.
- **오프라인** — 신호가 끊긴 곳에서 적은 쪽지도 기기에 먼저 남고, 연결되면 올라갑니다.
- **개인정보** — 쪽지는 이틀이 지나면 자동으로 지워집니다(오늘·어제 것만 남음).

## 쓰는 법

1. 처음 켜면 이름을 적고, **새 팀 만들기**(역에 한 사람) 또는 **코드로 들어가기**.
2. 팀을 만든 사람은 설정 화면의 **코드 보내기**로 여덟 글자 코드를 동료에게 보냅니다.
3. 아래의 **+ 출발 쪽지 / + 도착 쪽지**로 적습니다. 시간은 `1713`만 쳐도 `17:13`이 됩니다.

## 설정해야 하는 것 — Firebase 콘솔

당구 점수판과 같은 Firebase 프로젝트(`moneywalk-551ca`)를 씁니다. 데이터는 `teams/` 아래에만
있어서 점수판의 `users/`와 섞이지 않습니다. 콘솔에서 두 가지를 해야 합니다:

1. **Authentication → 로그인 방법 → 익명** 켜기. 동행은 계정 없이 익명으로 로그인합니다 —
   근무 중에 구글 계정을 꺼낼 일은 없고, 필요한 건 "이 폰이 누구인지" 하나뿐입니다.
2. **Firestore 규칙**에 `firestore.rules`의 `match /teams/...` 블록을 더하기. 저장소 맨 위의
   `firestore.rules`에 두 앱의 규칙이 합쳐져 있으니 그걸 통째로 붙여넣어도 됩니다.

색인은 따로 만들 필요가 없습니다 — 쪽지는 날짜 하나로만 묻습니다.

## 개발

이 폴더는 당구 점수판과 별개의 Graft 앱입니다. 프레임워크를 옆에 두고:

```bash
cd donghaeng
npm install            # graft는 상위 워크스페이스나 file: 의존으로
npx graft dev --port 3300
npx tsc --noEmit
node scripts/make-icons.mjs   # 아이콘 다시 만들기
```

## 안드로이드 앱

`donghaeng/` 아래가 바뀐 푸시마다 `.github/workflows/donghaeng.yml`이 APK를 지어
**`donghaeng-ci` 프리릴리스**에 올립니다. 폰에서 그 릴리스의 `donghaeng-ci.apk`를 받아 설치하면
됩니다. 서명은 점수판과 같은 시크릿(`ANDROID_KEYSTORE_BASE64` 등)을 씁니다.

패키지 이름이 `com.donghaeng.app`이라 당구 점수판과 한 폰에 같이 깔립니다. 점수판의
업데이트 버튼(`v*` 릴리스)과도 섞이지 않습니다.

## 코드가 어디 있는지

| 파일 | 무엇 |
| --- | --- |
| `lib/slip.ts` | 쪽지의 모양, 시각·날짜 계산, 공유 글. UI도 Firebase도 모릅니다 |
| `lib/firebase.ts` | 익명 로그인, 팀 만들기·들어가기, 쪽지 읽기·쓰기·지우기 |
| `lib/session.ts` | 이 폰의 이름과 팀 |
| `lib/platform.ts` | 기기 저장소·진동·공유 |
| `app/home.tsx` | 첫 화면 — 이름과 팀이 없으면 설정, 있으면 쪽지판 |
| `app/board.tsx` | 쪽지판 |
| `app/slip-card.tsx` | 목록의 쪽지 한 장 |
| `app/slip-sheet.tsx` | 펼친 쪽지 — 맡기, 완료, 공유, 고치기 |
| `app/slip-editor.tsx` | 쪽지 쓰기·고치기 |
| `app/settings/settings-panel.tsx` | 팀 코드, 구성원, 내 이름, 나가기 |
