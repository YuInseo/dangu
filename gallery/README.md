# 갤러리 뷰

기본 갤러리처럼 사진·앨범을 보되, **사진과 파일 정보를 한 화면에서 같이** 보는 앱.
점수판(웹 + Graft)과는 별개인 네이티브 안드로이드 앱(Kotlin · Jetpack Compose)이다.

## 무엇이 되나

- **사진 탭** — 날짜별로 묶인 전체 사진·동영상.
  - **격자 / 목록** 전환. 목록은 줄마다 썸네일 옆에
    파일 이름 · 해상도 · 크기 · 형식 · 시각 · 폴더 · 카메라/조리개/셔터/ISO가 같이 나온다.
  - 정렬(최신순 · 오래된순 · 이름순 · 큰 파일순), 격자 칸 수(2–7) 조절. 고른 값은 기억한다.
  - 줄 끝 ⓘ, 또는 사진을 길게 누르면 뷰어를 거치지 않고 전체 정보가 바로 뜬다.
- **앨범 탭** — 최근 항목 · 동영상 · 폴더별 앨범. 앨범 안에서도 격자/목록이 같다.
- **지도 탭** — 사진을 찍은 곳마다 썸네일 표식(가까운 사진은 한 표식에 장 수와 함께 묶임).
  표식을 누르면 그 장소 이름과 사진들이 아래에 뜨고, 누르면 뷰어로. 지도는 OpenStreetMap이라 키가 필요 없다.
  처음 한 번은 사진마다 EXIF 위치를 읽느라 시간이 걸리고(진행 막대), 그 뒤로는 새 사진만 읽는다.
- **뷰어** — 넘기기, 두 손가락/두 번 눌러 확대, 아래에 한 줄 요약, ⓘ로 전체 정보, 공유, 다른 앱으로 열기.
- **정보** — 날짜, 해상도(MP), 크기, 형식, 폴더 경로(눌러서 복사), 카메라·렌즈, 조리개·셔터·ISO·초점거리,
  플래시, 촬영 위치(주소 + 좌표, 눌러서 지도).

## "사진 정보" 패널 (AI 셀렉트처럼)

설치하면 런처에 아이콘이 **두 개** 생긴다: `갤러리 뷰`와 `사진 정보`.

`사진 정보`는 지금 보던 화면 위에 반투명 카드로 뜨는 패널이다.

- **엣지 패널에 넣기**: 설정 → 디스플레이 → 엣지 패널 → 앱 → `사진 정보` 추가.
  이제 어느 화면에서든 옆에서 쓸어 눌러 바로 띄운다. 가장 최근 사진들이 위에 줄지어 나오고,
  맨 앞(방금 찍은 사진이나 스크린샷)의 정보가 곧장 보인다.
- **기본 갤러리에서 보내기**: 삼성 갤러리에서 사진을 고르고 → 공유 → 맨 윗줄의 `사진 정보`.
  그 사진(여러 장이면 여러 장)의 정보를 띄운다. 공유 창 맨 윗줄(바로 공유)에 올라가도록
  공유 바로가기를 등록해 두었다. 삼성 갤러리의 선택 막대(만들기·공유·삭제·더보기) 자체에는
  다른 앱이 단추를 넣을 수 없어서, 이 길이 가장 짧다.

다른 앱이 지금 화면에 띄운 사진이 무엇인지는 안드로이드가 알려 주지 않는다. 그래서 "최근 사진"과
"공유로 보내기" 두 길을 둔다.

## 자동 업데이트

앱을 켜면 `gallery-latest` 릴리스의 `gallery-version.json`을 보고, 새 버전이면 APK를 뒤에서 받아 둔 뒤
위에 **"새 버전 준비됨 · 설치"** 카드를 띄운다. 안드로이드는 사이드로딩한 앱이 스스로를 조용히
설치하게 두지 않으므로 마지막 설치 확인 한 번은 사람이 누른다. 처음 한 번은 "이 출처 허용" 설정으로 안내된다.

## 빌드

`gallery/` 아래가 바뀌면 GitHub Actions(`.github/workflows/gallery.yml`)가 APK를 만든다.

- 휴대폰에서: 저장소의 Releases → **`갤러리 뷰 (최신 빌드)`** → `gallery-view.apk`
- 또는 Actions 실행 화면의 `gallery-view-apk` 아티팩트

점수판과 같은 서명 시크릿(`ANDROID_KEYSTORE_BASE64` 등)이 있으면 그 키로 서명하므로 다음 빌드를
그대로 덮어 설치할 수 있다.

로컬에서는 Android SDK가 있는 곳에서:

```bash
cd gallery
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

최소 Android 10 (API 29).
