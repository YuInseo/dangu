# Lumen

디스코드 대체 클라이언트(안드로이드). 기능은 디스코드 그대로, 겉모습만 다르다.

디스코드 공식 웹 클라이언트(`discord.com/app`)를 앱 안에 띄우고, 그 위에 Lumen의 테마와
네이티브 기능을 얹는다. Vencord·Vesktop과 같은 방식이다. 그래서 채팅, 서버, DM, 음성·영상 통화,
스레드, 이모지까지 전부 진짜 디스코드와 같게 동작한다.

로그인은 디스코드 페이지에서 한다. 앱은 비밀번호나 토큰을 따로 읽거나 보관하지 않는다.

> 디스코드 약관은 수정된 클라이언트를 금지한다. 이 방식은 평범한 브라우저와 같은 요청만 보내므로
> 제재 사례는 드물지만, 위험이 0은 아니다. 디스코드와 관계없는 비공식 앱이다.

## 무엇이 되나

- **테마** — 미드나잇(순검정) · 오션 · 포레스트 · 로즈 · 모카 · 페이퍼(밝은) · 원래대로.
  디스코드의 CSS 변수를 덮어써서 새로고침 없이 바로 바뀐다.
- **떠 있는 단추** — 화면 가장자리의 작은 동그라미. 끌어서 옮기고, 누르면 설정, **길게 누르면
  사이드바(서버·채널 목록) 숨기기/보이기** — 휴대폰 폭에서 채팅을 넓게 쓰는 핵심 기능.
- **화면** — 멤버 목록 숨기기, Nitro·선물 권유 숨기기, 넓은 레이아웃(PC처럼), 글자 크기, 모서리 둥글기.
- **사용자 CSS** — Vencord QuickCSS처럼 직접 CSS를 넣는다.
- **알림** — 앱이 뒤에 있을 때 새 메시지·멘션을 안드로이드 알림으로.
- **파일** — 첨부는 안드로이드 파일 선택기, 받은 파일은 `다운로드/Lumen/`.
- **음성·영상 통화** — 마이크·카메라 권한을 물은 뒤 그대로.
- **링크** — discord.gg 초대·discord.com 링크를 Lumen으로 연다. 바깥 링크는 브라우저로.
- **공유로 보내기** — 다른 앱에서 사진을 "공유 → Lumen"으로 보내면, 채널에서 파일 올리기를 누를 때
  고르는 창 없이 바로 첨부된다. 글은 클립보드로.
- **자동 업데이트** — 켜질 때 `lumen-latest` 릴리스를 확인하고 새 APK를 받아 둔 뒤 "설치" 카드.

## 한계

- 알림은 앱 프로세스가 살아 있을 때만 온다(디스코드 푸시 서버는 공식 앱에만 보낸다).
  뒤로 가기를 눌러도 앱을 끄지 않고 뒤로 보내는 이유다.
- 화면을 끈 채 오래 음성 통화를 하면 안드로이드가 앱을 멈출 수 있다.
- 디스코드가 웹 클라이언트의 클래스 이름을 바꾸면 사이드바 숨기기 같은 레이아웃 조정이 잠시 안 먹을 수
  있다(색 테마는 변수라 오래 버틴다).

## 빌드

`lumen/` 아래가 바뀌면 GitHub Actions(`.github/workflows/lumen.yml`)가 APK를 만든다.
휴대폰에서는 저장소의 Releases → **`Lumen (최신 빌드)`** → `lumen.apk`.

```bash
cd lumen
./gradlew assembleDebug
```

최소 Android 10 (API 29).
